# NASCAR Predictor V2.0

Race-agnostic rebuild of V1.6.

## Permanent repository files
- app.py
- nascar_predictor_pro.py
- requirements.txt
- driver_priors_template.csv
- track_profile_template.csv
- practice_qualifying_template.csv

## Weekly workflow
1. Upload DraftKings salaries.
2. Upload weekly driver priors using generic track-type and track-history fields.
3. Upload one track profile.
4. Before qualifying: research projections only.
5. After qualifying: upload the completed practice/qualifying file; final GPP portfolio unlocks.
6. After race: upload actual results to create the audit.

Do not commit weekly projections, exposures, scenarios, or lineups to the repository.
Legacy Las Vegas column aliases remain supported in the engine only for backward compatibility.
