# NASCAR Predictor V2.1 — Auto Setup

Weekly workflow:
1. Select the track from the built-in catalog.
2. Upload DraftKings salaries.
3. Optional: upload enriched driver priors. Without them the app uses DK FPPG as a broad baseline and keeps missing specialized signals neutral.
4. After practice/qualifying, upload the completed grid to unlock final GPP builds.
5. Run simulations and export the portfolio.
6. Upload actual results after the race for audit.

No weekly track-profile CSV is required.
