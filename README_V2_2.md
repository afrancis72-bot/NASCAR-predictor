# NASCAR Predictor V2.2 — Auto Driver DNA

Normal weekly workflow:
1. Select track.
2. Upload DraftKings salaries.
3. Driver DNA auto-builds from available DK salary/FPPG plus Track DNA.
4. Saturday: use Live Update for practice and official qualifying.
5. Run coherent race simulations and build the final DFS portfolio.
6. Audit after the race.

Important: V2.2 does not fabricate unavailable recent speed, track history, comparable-track performance, or DNF data.
The optional enriched-priors upload remains under Advanced as an override until a trustworthy automated public data source is integrated.
