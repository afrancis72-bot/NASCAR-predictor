# NASCAR Predictor V2.4 — Source Diagnostic

This is intentionally a diagnostic release, not a new modeling release.

Use the Source Diagnostic tab from the deployed Streamlit app to test:
- NASCAR Feed Drivers
- NASCAR Feed Driver Summary
- NASCAR Feed Season Stats
- NASCAR Reference home/drivers/results/entry-list pages

The test runs from the same server that runs the model, so it tells us whether a source is actually usable before we integrate it.
No source-test result changes Driver DNA automatically in V2.4.
